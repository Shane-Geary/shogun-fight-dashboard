# **SFC Client Management System**

## Shogun Fight Collective weekly audit dashboard

## The Shogun Fight Collective Client Management System is a web-based application designed to streamline weekly student record audits by consolidating data from Martialytics and Jotform into a unified dashboard. The application provides centralized record management, search and filtering capabilities, data visualization, and secure access for authorized staff, reducing manual administrative work and improving operational efficiency.
